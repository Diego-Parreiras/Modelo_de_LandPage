# 🏢 Imobiliária Sincera | Projeto Prático Web

Um projeto prático desenvolvido com o objetivo de estudar, testar e consolidar conhecimentos fundamentais de desenvolvimento Front-End: **HTML5**, **CSS3** e **JavaScript Vanilla**. 

O projeto apresenta uma *Landing Page* satírica de uma imobiliária que vende "experiências de sobrevivência" (com um toque de humor e ironia no copywriting), enquanto o código por trás mantém um rigor profissional focado em responsividade, UI/UX e boas práticas.

## 🚀 Principais Funcionalidades e Aprendizados

Durante o desenvolvimento deste projeto, foram aplicados e resolvidos diversos desafios reais de interface:

* **Design Responsivo & Mobile-First:** Layout totalmente adaptável para Desktop, Tablets e Celulares utilizando CSS Flexbox, CSS Grid e Media Queries.
* **Galeria Lightbox Interativa:** Um sistema de visualização de imagens em tela cheia criado 100% com JavaScript puro. Possui suporte para navegação por botões, teclado (setas direccionais e tecla *Esc*) e eventos de toque ( *swipe* lateral) para dispositivos móveis.
* **Componentização via JavaScript:** Implementação de um sistema simples de injeção de dependências (DOM), onde o rodapé global é injetado via JS em todas as páginas para manter o princípio DRY (*Don't Repeat Yourself*).
* **Arquitetura CSS Estruturada:** Uso extensivo de variáveis (`:root`) para padronização de paleta de cores, tipografia e espaçamentos matemáticos (`vh`, `vw`, `%`), além de customização de Scrollbar.
* **Ajustes Finos de UI/UX:** Correção de *overflows* indesejados, ajustes de *Safe Area* para telas de celulares modernos (*notches*) e manipulação da hierarquia de leitura no mobile utilizando a propriedade `order` do CSS.

## 🛠️ Tecnologias Utilizadas

* **HTML5** (Semântica e Estruturação)
* **CSS3** (Estilização, Flexbox, Grid, Animações e Responsividade)
* **JavaScript** (Lógica de interação, manipulação de DOM e escuta de eventos)

## 💡 Nota sobre o uso de Inteligência Artificial

Este projeto foi construído "à mão" com o foco em praticar a escrita de código. No entanto, a Inteligência Artificial foi utilizada como uma aliada educacional ( *Pair Programming* ). A IA ajudou a debugar comportamentos inesperados do CSS, discutir melhores práticas de estruturação e a gerar comentários orgânicos para documentar o código de forma clara e profissional.

## 📁 Como rodar o projeto

1. Faça o clone deste repositório.
2. Abra a pasta do projeto no seu editor de código (como o VS Code).
3. Abra o arquivo `index.html` no seu navegador (recomenda-se o uso da extensão *Live Server* para melhor experiência).
